# Typography

Use the theme's display face for headings, its body face for paragraphs and its monospace face for code. These are the families used by the renderer.

| Theme | Display | Body | Monospace |
| --- | --- | --- | --- |
| Tokyo Night | Clash Display | Switzer | Commit Mono |
| Dracula | Satoshi | IBM Plex Sans | IBM Plex Mono |
| Gruvbox | Vollkorn | Source Sans 3 | Source Code Pro |
| Solarized Dark and Light | Newsreader | Literata | Fira Code |
| GitHub Dark and Light | Atkinson Hyperlegible Next | Atkinson Hyperlegible Next | JetBrains Mono |
| Professional | Plus Jakarta Sans | Source Serif 4 | JetBrains Mono |
| Dark | General Sans | Inter | Fira Code |
| Technical | Azeret Mono | Inter | Azeret Mono |
| Minimal | Cormorant | Lora | Commit Mono |
| Creative | DM Sans | DM Sans | Victor Mono |

Body text starts at 1rem with a line height of 1.6. Headings follow a 1.25 type scale and use tighter line height and letter spacing. When display and body share a family, size and weight distinguish the heading.

Keep long paragraphs to about 65 characters per line. Let charts use extra width when axis labels need it. Check headings and labels with the fallback fonts as well as the theme fonts.
